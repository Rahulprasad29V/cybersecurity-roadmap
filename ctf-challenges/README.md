# CyberWolf CTF-Style Challenges

A collection of offline, safe puzzles for practicing analytical thinking. These are not live targets and do not require network scanning, exploitation, credential attacks or external systems.

## Challenge levels
| Level | Challenge | Skills |
|---|---|---|
| Beginner | [Decode the Note](beginner/decode-the-note.md) | Encoding recognition |
| Beginner | [Spot the Timeline](beginner/spot-the-timeline.md) | Log analysis |
| Beginner | [Hash Detective](beginner/hash-detective.md) | File integrity |
| Intermediate | [Access Matrix](intermediate/access-matrix.md) | Authorization reasoning |
| Intermediate | [Header Inspector](intermediate/header-inspector.md) | Defensive web configuration |

## Rules
- Solve using the data included in the challenge.
- Flags are fictional completion tokens, not credentials.
- Do not point tools at third-party systems.
- Hints are included to support learning; solutions explain the reasoning.
- Record what evidence supports your answer.

## Flag format
`CYBERWOLF{short_lowercase_answer}`

## Create a challenge
Use [challenge-template.md](challenge-template.md). Keep tasks self-contained, safe, accessible and reproducible.
