# Security Policy

## Scope
This repository is an educational documentation and learning resource, not a production software product.

## Reporting repository concerns
For a security concern in this repository's own content, workflow or configuration, use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the maintainers privately through the contact information on the repository profile.

Do not include secrets, personal data or details that expose a third-party system in a public issue.

## Learning environment safety
- Use isolated virtual machines and snapshots.
- Use synthetic data wherever possible.
- Do not expose intentionally vulnerable services to public networks.
- Do not test systems without explicit authorization.
- Follow the training platform's rules and engagement scope.
- Stop immediately if scope or safety is uncertain.
