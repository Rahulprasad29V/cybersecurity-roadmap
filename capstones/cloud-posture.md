# Capstone: Cloud Security Posture Assessment

**Level:** Advanced · **Suggested effort:** 10–16 hours

## Scenario
A fictional organization is migrating a learner-facing service to cloud infrastructure. The provided synthetic configuration findings include IAM, network, storage and logging concerns.

## Scope
Use the supplied synthetic dataset or a sandbox account you control. A real account requires explicit owner authorization. Check billing and cleanup before creating resources.

## Work packages
1. Define assets, owners, data classification and trust boundaries.
2. Review [cloud-posture-findings.csv](../datasets/cloud-posture-findings.csv).
3. Review IAM access and identify excessive or dormant privilege.
4. Assess network exposure and data storage assumptions.
5. Review logging, alerting, encryption and backup evidence.
6. Prioritize remediation with business impact and dependencies.
7. Define retest evidence and exception-expiry controls.

## Required outputs
- Cloud context diagram.
- Asset and ownership inventory.
- Prioritized findings register.
- Least-privilege recommendation.
- Logging and recovery gap analysis.
- Remediation roadmap.

## Acceptance criteria
Every finding states evidence, impact, uncertainty, owner, priority, due date and a verifiable closure condition.
