# CyberWolf Advanced Capstones

A capstone combines multiple disciplines into one documented outcome. Select one scenario, agree its scope, build the required evidence and complete the review rubric.

## Capstone catalog

| Capstone | Primary skills | Deliverables |
|---|---|---|
| [Enterprise architecture review](architecture-review.md) | Threat modeling, identity, network and risk | Architecture pack and threat register |
| [Detection engineering program](detection-program.md) | Telemetry, detections, tuning and operations | Detection pack and test matrix |
| [Secure SDLC transformation](secure-sdlc.md) | DevSecOps, supply chain and secure design | Delivery control plan |
| [Cloud posture assessment](cloud-posture.md) | IAM, storage, network and cloud governance | Prioritized posture report |
| [Incident response exercise](incident-response.md) | Command, investigation and resilience | Incident action plan and retrospective |

## Minimum submission package
- Project brief with scope, assumptions and acceptance criteria.
- Context or architecture diagram where relevant.
- Methodology and evidence log.
- Findings with supporting evidence and limitations.
- Remediation or improvement plan with owners and priority.
- Validation and retest strategy.
- Final executive summary.
- Retrospective and future work.

## Completion gate
Use the [capstone evaluation rubric](../assessments/rubrics/capstone.md). A capstone is complete when evidence is reproducible, safety boundaries are respected, limitations are explicit and the recommendations are actionable—not merely when every section is filled in.
