# CyberWolf Learning Resources

This directory prioritizes official documentation, standards organizations and reputable training providers. Availability and pricing can change; verify details on the publisher's website.

## Start here
- [CISA](https://www.cisa.gov/) — cybersecurity guidance and advisories.
- [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) — cybersecurity risk management.
- [OWASP](https://owasp.org/) — application security projects and guidance.
- [MITRE ATT&CK](https://attack.mitre.org/) — adversary tactics and techniques knowledge base.
- [CIS Controls](https://www.cisecurity.org/controls) — prioritized safeguards.
- [Cloud Security Alliance](https://cloudsecurityalliance.org/) — cloud security guidance.
