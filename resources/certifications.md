# Cybersecurity Certification Roadmap

Certifications can structure learning, but they do not replace practical competence. Compare current exam objectives, prerequisites, fees, renewal rules and local recognition before paying.

## Foundational options to research
- CompTIA A+ for broad IT support foundations.
- CompTIA Network+ for networking foundations.
- ISC2 Certified in Cybersecurity (CC); check current eligibility and program terms.
- Microsoft and cloud-provider fundamentals credentials.

## Security foundations
- CompTIA Security+.
- Reputable introductory blue-team or security fundamentals credentials.

## Specialist pathways
| Career direction | Study before choosing an exam |
|---|---|
| SOC / Blue Team | Networking, Windows/Linux logs, SIEM, incident response |
| Penetration Testing | Networking, Linux, web security, methodology, reporting |
| Application Security | Secure coding, OWASP, threat modeling, code review |
| Cloud Security | Cloud IAM, networking, logging, containers, architecture |
| DFIR | Operating systems, filesystems, evidence handling, timelines |
| GRC | Risk, controls, audit, policy, privacy and frameworks |

## Advanced credentials to research
Examples include OSCP and other practical penetration-testing credentials, CISSP for experienced security professionals, CISM for security management, and professional cloud security certifications. Requirements and exam versions change; consult the issuing organization.

## Selection checklist
- Does the syllabus match your target role?
- Do you meet the prerequisites and experience requirements?
- Is the credential recognized in your target market?
- Can you afford exam, lab, renewal and retake costs?
- Have you built practical projects that demonstrate the same skills?
