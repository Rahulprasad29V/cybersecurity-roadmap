# Free and Freemium Learning Resources

- [Cisco Networking Academy](https://www.netacad.com/) — networking and IT learning.
- [Microsoft Learn](https://learn.microsoft.com/) — Microsoft technologies and security.
- [AWS Skill Builder](https://skillbuilder.aws/) — AWS learning content; check course access terms.
- [Google Cloud Skills Boost](https://www.cloudskillsboost.google/) — cloud learning; check free-tier availability.
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — free web security learning and labs.
- [OverTheWire](https://overthewire.org/wargames/) — command-line and security wargames.
- [picoCTF](https://picoctf.org/) — CTF learning.
- [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) — intentionally insecure training application.
- [OpenLearn](https://www.open.edu/openlearn/) — broad academic resources.
- [freeCodeCamp](https://www.freecodecamp.org/) — programming and web development.

Check each provider's current terms, availability and pricing.
