# Books, Reports and Reading

Check the publisher's licensing and use current editions where available.

## Books to explore
- *The Practice of Network Security Monitoring* — Richard Bejtlich.
- *Security Engineering* — Ross Anderson.
- *The Web Application Hacker's Handbook* — Dafydd Stuttard and Marcus Pinto (older; pair with current OWASP and PortSwigger material).
- *Computer Networking: A Top-Down Approach* — James Kurose and Keith Ross.
- *The Linux Command Line* — William Shotts.
