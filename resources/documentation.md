# Official Documentation and Standards

## Networking and systems
- [RFC Editor](https://www.rfc-editor.org/) — Internet standards and RFCs.
- [Linux man-pages](https://man7.org/linux/man-pages/) — Linux system interfaces and commands.
- [Microsoft Learn](https://learn.microsoft.com/) — Windows, PowerShell and security documentation.
- [Python documentation](https://docs.python.org/3/) — Python language and standard library.
- [Git documentation](https://git-scm.com/doc) — Git reference.

## Security
- [NIST Computer Security Resource Center](https://csrc.nist.gov/)
- [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework)
- [OWASP Top 10](https://owasp.org/www-project-top-ten/)
- [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/)
- [MITRE ATT&CK](https://attack.mitre.org/)
- [CIS Controls](https://www.cisecurity.org/controls)
- [CISA Known Exploited Vulnerabilities Catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)
- [FIRST CVSS](https://www.first.org/cvss/)
- [CVE Program](https://www.cve.org/)

Prefer official documentation for the exact version of a tool or platform. Do not rely solely on old blog posts or copied commands.
