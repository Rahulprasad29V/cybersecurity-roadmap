# Practical Lab Catalog

All activities below are designed for local, synthetic or explicitly authorized environments. Record scope, prerequisites, expected evidence and cleanup.

| Lab | Level | Skills | Brief |
|---|---|---|---|
| [Packet review](exercises/packet-review.md) | Beginner | DNS, TCP, HTTP metadata | Explain a benign capture |
| [Log triage](exercises/log-triage.md) | Beginner | Authentication events, timelines | Investigate synthetic login records |
| [File integrity](exercises/file-integrity.md) | Beginner | Hashes, evidence | Verify changes in a test directory |
| [Web security review](exercises/web-security-review.md) | Intermediate | Access control, secure design | Review a local demo application |
| [Cloud configuration review](exercises/cloud-review.md) | Intermediate | IAM, storage, network | Review a sample architecture |

## Standard lab workflow
1. Read the brief and identify prerequisites.
2. Confirm the environment is yours or explicitly authorized.
3. Record scope, constraints and stop conditions.
4. Perform the activity using synthetic or approved data.
5. Save sanitized evidence and explain uncertainty.
6. Complete the report template and cleanup.
7. Revert snapshots or remove temporary resources.
