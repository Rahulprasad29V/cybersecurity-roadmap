# Lab: Cloud Configuration Review

**Level:** Intermediate · **Effort:** 60–90 minutes

## Objective
Review a sample or sandbox cloud architecture for identity, network and storage risks.

## Authorized environment
Use a sample configuration dataset or a cloud account you control. Check costs before enabling paid services. Never review an employer or third-party account without written authorization.

## Activity
1. Identify assets and trust boundaries.
2. Review sample IAM roles and identify excessive permissions.
3. Review storage access assumptions and logging coverage.
4. Inspect the architecture for unnecessary public exposure.
5. Prioritize remediation by risk and operational impact.

## Evidence
- Sanitized architecture diagram.
- Risk-ranked findings with assumptions.
- Least-privilege recommendations and verification approach.

## Success criteria
Each finding identifies the asset, weakness, potential impact, evidence, limitation and owner action.
