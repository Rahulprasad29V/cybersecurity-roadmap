# Lab: Local Web Security Review

**Level:** Intermediate · **Effort:** 60–90 minutes

## Objective
Review a deliberately vulnerable local training application and explain one weakness with a defensive fix.

## Authorized environment
Use a local OWASP Juice Shop instance or a training lab explicitly assigned by its provider. Do not test public websites or real customer data.

## Activity
1. Document application version and local lab scope.
2. Review one feature for authentication, authorization, input handling or session security.
3. Reproduce the issue only using the lab's intended exercise.
4. Explain root cause and realistic impact.
5. Identify a defensive design change and a regression test.

## Evidence
- A sanitized lab report.
- A concise root-cause explanation.
- Proposed fix and regression-test scenario.

## Success criteria
Show how the fix addresses the root cause. Do not include real credentials, session tokens or private data.
