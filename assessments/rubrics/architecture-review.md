# Rubric: Architecture Review

| Criterion | 0 — Not demonstrated | 2 — Developing | 4 — Advanced |
|---|---|---|---|
| System context | Missing | Major actors identified | Purpose, assets, actors and dependencies clear |
| Trust boundaries | Missing | Some boundaries shown | Identity, data and control boundaries justified |
| Threat analysis | Generic list | Threats mapped to some assets | Abuse cases, assumptions and attack paths reasoned |
| Control design | Controls named only | Some control mapping | Preventive, detective and recovery controls mapped to threats |
| Verification | No evidence plan | Partial verification | Measurable tests, telemetry and ownership |
| Risk decisions | No residual risk | Risks ranked but unclear | Trade-offs, owners and acceptance authority explicit |
| Communication | Difficult to follow | Understandable | Clear for technical and business audiences |

## Critical gate
The diagram must not expose real credentials, private endpoints or confidential architecture without owner permission.
