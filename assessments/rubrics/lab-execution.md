# Rubric: Lab Execution

Score each criterion from 0–4 using the [assessment scale](../README.md).

| Criterion | 0 | 2 — Developing | 4 — Advanced |
|---|---|---|---|
| Scope and authorization | Missing or unauthorized | Scope partly clear | Explicit, bounded and checked throughout |
| Preparation | No prerequisites or safety plan | Basic setup documented | Dependencies, risks, rollback and stop conditions planned |
| Method | No reproducible method | Main steps present | Clear, proportionate and repeatable method |
| Evidence | Missing or sensitive | Evidence exists but context is weak | Sanitized, timestamped and linked to claims |
| Analysis | Unsupported conclusion | Some interpretation | Facts, assumptions and uncertainty separated |
| Cleanup | Not documented | Partial cleanup | Verified reset and data handling |
| Reflection | Missing | Lists what happened | Explains trade-offs and next learning steps |

## Critical gate
Any unauthorized testing, exposure of private data or unsafe use of live systems means the activity is not accepted, regardless of numeric score.
