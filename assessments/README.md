# CyberWolf Assessment Framework

Assessment in this repository is formative. It supports learning and review; it is not an accredited examination, hiring decision, formal certification or proof of professional competence.

## Assessment components
- **Knowledge checks:** JSON quizzes with answer explanations.
- **Practical work:** lab evidence and reflections.
- **Scenario analysis:** synthetic cases and CTF-style reasoning.
- **Portfolio:** capstone documents and reproducible project artifacts.
- **Review:** rubrics for technical quality, communication and safety.

## Rubrics
| Rubric | Evaluates |
|---|---|
| [Lab execution](rubrics/lab-execution.md) | Scope, method, evidence, validation and cleanup |
| [Technical report](rubrics/technical-report.md) | Accuracy, evidence, impact and remediation |
| [Architecture review](rubrics/architecture-review.md) | Trust boundaries, threat model and controls |
| [Capstone](rubrics/capstone.md) | Integration, rigor, deliverables and reflection |
| [Oral defense](rubrics/oral-defense.md) | Explanation, reasoning and response to critique |

## Performance scale
| Score | Label | Meaning |
|---:|---|---|
| 0 | Not demonstrated | No usable evidence |
| 1 | Emerging | Partial understanding; substantial guidance required |
| 2 | Developing | Mostly correct; gaps or inconsistent evidence remain |
| 3 | Proficient | Correct, reproducible and independently explained |
| 4 | Advanced | Strong judgment, trade-off analysis and clear limitations |

A score should always include comments and evidence references. Do not average away a critical safety failure; it requires remediation before the work is accepted.
