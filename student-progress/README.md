# Learner-Owned Progress Tracking

This repository is content-first. Progress files are templates for a learner's **own local copy**; they are not uploaded to a central student database.

## Quick start
1. Copy `student-profile.template.json` to a private filename such as `my-profile.json`.
2. Copy `progress.template.csv` to `my-progress.csv`.
3. Track completion locally and update weekly.
4. Keep personal reflections and sensitive evidence outside the public repository.
5. Publish only a sanitized portfolio item when you are comfortable sharing it.

## What to track
- Selected learning path and current roadmap stage.
- Challenge day, topic, status and completion date.
- Quiz attempts as private self-assessment.
- Lab or project evidence stored in a safe location.
- Next action and review date.

## Status values
Use one of: `not_started`, `learning`, `practicing`, `completed`, `needs_review`.

## Privacy
Do not commit your real name, email, phone number, student ID, organization, access tokens, private notes or unredacted screenshots. The template is a learning aid, not an official student record.

## Limitation
GitHub Markdown and CSV files do not automatically synchronize learner progress, authenticate students, grade quizzes, issue verified achievements or enforce per-user access. Those features would require a separate application and backend.
