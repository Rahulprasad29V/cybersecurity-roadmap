# CyberWolf Cybersecurity Glossary

The glossary gives concise, learner-friendly definitions. It is a starting point: terms may have discipline-specific meanings, and standards or vendor documentation should be consulted for precise usage.

- Browse [glossary.csv](glossary.csv) in a spreadsheet or text editor.
- Add terms alphabetically.
- Keep definitions concise and neutral.
- Include an authoritative reference for specialist or contested definitions.
- Avoid including exploit recipes or sensitive operational data.
