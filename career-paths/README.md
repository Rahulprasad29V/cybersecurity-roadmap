## Career readiness checklist
- [ ] Explain core networking and operating-system concepts.
- [ ] Demonstrate one specialization-specific practical skill.
- [ ] Complete at least two documented projects.
- [ ] Write a clear technical report for a non-specialist reader.
- [ ] Explain limitations and ethical boundaries.
- [ ] Review current job descriptions in the target market and identify skill gaps.
- [ ] Prepare evidence-based examples for interviews.

## Suggested portfolio layout
```text
portfolio/
├── README.md
├── project-01/
│   ├── README.md
│   ├── methodology.md
│   └── evidence/
├── project-02/
└── reports/
```

Sanitize every artifact. Never upload client data, real incident records, credentials, private targets or employer-confidential material.
