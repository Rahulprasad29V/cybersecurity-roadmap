# Cybersecurity Tools Guide

Tools help answer questions; they do not replace understanding or authorization.

| Tool | Primary use | Learning objective |
|---|---|---|
| Wireshark | Packet analysis | Interpret protocol metadata and traffic flows |
| Nmap | Network discovery and service inventory | Understand ports, services and scan limitations in a lab |
| Burp Suite Community | Web request inspection | Understand HTTP in training labs |
| OWASP ZAP | Web application testing | Learn passive analysis and safe lab testing |
| Git | Version control | Track changes and collaborate |
| Python | Automation and analysis | Parse files and synthetic logs |
| Sysmon | Windows telemetry | Understand process and event data |
| Windows Event Viewer | Event inspection | Review system and security events |
| Zeek | Network security monitoring | Explore structured network logs |
| Suricata | Network threat detection | Understand IDS alerts and rule concepts |
| Docker | Containers | Build and inspect isolated environments |

## Tool-use checklist
- Confirm authorization and target scope.
- Read official documentation.
- Use conservative settings in a lab.
- Understand what the tool sends or changes.
- Validate findings manually where appropriate.
- Record version, configuration, limitations and evidence.
- Do not publish target-sensitive output.
