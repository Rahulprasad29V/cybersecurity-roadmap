# Computer Fundamentals

Understand the systems cybersecurity professionals protect.

## Core concepts
- CPU, RAM, persistent storage, firmware and peripherals.
- Boot process, operating-system kernel, processes and threads.
- Filesystems, paths, metadata, file signatures and permissions.
- Virtual machines, hypervisors, containers, snapshots and backups.
- Binary and hexadecimal number systems.

## Practice
1. Inspect system information on your own computer.
2. Create a disposable virtual machine and take a clean snapshot.
3. Compare the extension, size, signature and hash of harmless sample files.
4. Draw a simple diagram of hardware, OS and applications.

## Check your understanding
- How do RAM and persistent storage differ?
- Why are snapshots useful during lab work?
- Why should file type not be trusted solely from its extension?
