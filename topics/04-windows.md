# Windows Fundamentals

Learn Windows administration and security telemetry.

## Core concepts
- Users, groups, NTFS permissions, services, processes and scheduled tasks.
- PowerShell fundamentals and safe command execution.
- Event Viewer, event channels, event fields and audit policy concepts.
- Microsoft Defender, Windows Firewall, updates, BitLocker and Secure Boot concepts.

## Practice
Review security and system events on your own Windows machine or a disposable VM. Inspect running processes and services. Create a harmless PowerShell report from synthetic data.

## Check your understanding
- What is the purpose of Windows Event Logs?
- How do NTFS permissions affect access?
- Why is least privilege important for administrators?
