# Cryptography

Understand the purpose and correct use of cryptographic building blocks.

## Core concepts
- Encoding, encryption, hashing and digital signatures.
- Symmetric and asymmetric cryptography.
- Salts, password hashing, key derivation and key management.
- Certificates, public key infrastructure, TLS and trust chains.
- Common implementation mistakes and cryptographic agility.

## Practice
Hash sample files and verify a file using a publisher-provided checksum. Inspect certificate details for a website you visit. Use a maintained library rather than implementing cryptographic algorithms yourself.

## Check your understanding
- Can a hash be decrypted?
- Why should passwords not be stored with a fast general-purpose hash alone?
- What does certificate validation help establish?
