# Web Application Security

Understand common application weaknesses and how to prevent them.

## Core concepts
- HTTP requests/responses, headers, cookies, sessions, browser security model and CORS.
- Access control, authentication, session management and secure password reset.
- Injection, XSS, CSRF, SSRF, path traversal and insecure file handling.
- Security misconfiguration, vulnerable components, logging and error handling.
- OWASP Top 10, ASVS, threat modeling, SAST, DAST and dependency scanning.

## Practice
Use PortSwigger Web Security Academy or a local OWASP Juice Shop instance. Complete beginner labs and record root cause, impact and fix. Patch a deliberately vulnerable local sample and add regression tests.

## Check your understanding
- Why is client-side validation insufficient?
- How does output encoding reduce XSS risk?
- Why should authorization be checked server-side for every sensitive action?
