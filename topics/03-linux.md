# Linux Fundamentals

Become comfortable administering and investigating Linux systems.

## Core concepts
- Filesystem hierarchy, shell navigation, pipes, redirection and text processing.
- Users, groups, permissions, sudo, ownership and least privilege.
- Processes, services, package management, SSH, scheduled tasks and logs.
- Updates, firewall basics, disk usage and troubleshooting.

## Practice
Use a disposable Linux VM. Create a non-administrator user, inspect system and authentication logs, and write a short script that summarizes a provided synthetic log file.

## Check your understanding
- Explain read/write/execute permissions.
- Why should daily work avoid unnecessary root access?
- Where would you look for service and authentication events?
