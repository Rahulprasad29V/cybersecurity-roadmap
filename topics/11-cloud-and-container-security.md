# Cloud and Container Security

Understand shared responsibility and protect cloud-native workloads.

## Core concepts
- Shared responsibility, cloud IAM, roles, policies and least privilege.
- Network security groups, private networking, logging and storage permissions.
- Secrets management, encryption, key rotation and workload identity.
- Container images, registries, runtime isolation and image provenance.
- Kubernetes RBAC, network policies, admission controls and IaC security.

## Practice
Use a sandbox or local emulator. Review a sample IAM policy for excessive permissions. Scan your own container image with a reputable scanner. Add dependency and secret scanning to a demo CI workflow.

## Check your understanding
- What does shared responsibility mean?
- Why should secrets not be baked into container images?
- What is the purpose of Kubernetes RBAC?
