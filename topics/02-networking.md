# Networking Fundamentals

Understand how devices communicate and how to interpret network traffic.

## Core concepts
- OSI and TCP/IP models; encapsulation.
- Ethernet, MAC addresses, ARP, IPv4, IPv6 and subnetting.
- TCP handshakes, UDP, ICMP, ports, sockets, routing and NAT.
- DNS, DHCP, HTTP/S, SSH, SMTP and NTP.
- Firewalls, proxies, VPN concepts, segmentation and wireless basics.

## Practice
1. Draw a diagram of your own network without publishing sensitive details.
2. Inspect local interface and route configuration.
3. Capture a DNS query generated by your own device in Wireshark.
4. Explain source/destination IP, ports, protocol and direction.

## Check your understanding
- How do TCP and UDP differ?
- What problem does DNS solve?
- What does a default gateway do?
- Why does HTTPS not hide all network metadata?
