# Topic Guides

Study these guides alongside the [main roadmap](../ROADMAP.md). Each topic should be learned through explanation, safe practice, reflection and evidence.

| Guide | What it covers |
|---|---|
| [Computer fundamentals](01-computer-fundamentals.md) | Hardware, operating systems, processes, files and virtualization |
| [Networking](02-networking.md) | TCP/IP, addressing, DNS, HTTP, routing and firewalls |
| [Linux](03-linux.md) | Shell, permissions, services, packages and logs |
| [Windows](04-windows.md) | Accounts, services, PowerShell and Event Viewer |
| [Programming and scripting](05-programming-and-scripting.md) | Python, Bash, PowerShell, JavaScript and Git |
| [Security fundamentals](06-security-fundamentals.md) | CIA, risk, controls, identity and least privilege |
| [Cryptography](07-cryptography.md) | Hashes, encryption, signatures, certificates and TLS |
| [Defensive security](08-defensive-security.md) | Logging, SIEM, detection, triage and response |
| [Ethical hacking methodology](09-ethical-hacking-methodology.md) | Scope, authorized assessment, validation and reporting |
| [Web application security](10-web-application-security.md) | HTTP, access control, injection and secure design |
| [Cloud and containers](11-cloud-and-container-security.md) | IAM, cloud posture, Docker and Kubernetes |
| [DFIR](12-digital-forensics-and-incident-response.md) | Evidence, timelines, investigation and incident response |
| [Malware analysis](13-malware-analysis.md) | Safe handling, static analysis and detection concepts |
| [Identity and access management](14-identity-and-access-management.md) | MFA, SSO, RBAC, privileged and service accounts |
| [GRC](15-governance-risk-and-compliance.md) | Risk, policies, controls, audits and frameworks |

Only practise on systems you own or have explicit written authorization to assess.
