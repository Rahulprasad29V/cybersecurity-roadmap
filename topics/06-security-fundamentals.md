# Security Fundamentals

Learn the principles and vocabulary used across cybersecurity disciplines.

## Core concepts
- Confidentiality, integrity, availability, privacy and safety.
- Threats, vulnerabilities, exploits, risk, likelihood and impact.
- Attack surface, defense in depth, least privilege and secure defaults.
- Authentication, authorization, accounting, MFA and session concepts.
- Security policies, asset inventory, patching, backups and awareness.

## Practice
Threat-model a simple student portal. Create a fictional asset inventory. Map risks to preventive, detective and corrective controls.

## Check your understanding
- How is a vulnerability different from a threat?
- What is defense in depth?
- Why is MFA not a replacement for secure authorization?
