# Defensive Security

Develop skills in monitoring, detection, triage and response.

## Core concepts
- Asset and vulnerability management.
- Endpoint, identity, application and network telemetry.
- SIEM concepts, log normalization, alert triage and detection engineering.
- IDS/IPS, endpoint detection, threat intelligence and threat hunting.
- Incident response, containment, eradication, recovery and lessons learned.

## Practice
Analyze synthetic login events. Write a triage note separating facts from hypotheses. Describe a detection idea and discuss false positives. Run a tabletop exercise using a fictional incident.

## Check your understanding
- Why preserve evidence before making changes?
- What makes an alert actionable?
- How do false positives affect analysts?
