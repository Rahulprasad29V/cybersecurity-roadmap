# Beginner Projects

## 1. Personal Cybersecurity Baseline
**Goal:** Create a checklist for securing a personal workstation and accounts.
- Review updates, screen lock, disk-encryption availability, firewall, backups, MFA and password-manager use.
- Do not publish private configuration or account details.
- **Deliverable:** checklist, rationale and verification steps.

## 2. Python Log Summary Tool
**Goal:** Parse synthetic logs and summarize event counts.
- Read a local sample file.
- Handle malformed lines and missing fields.
- Output counts and a clear error summary.
- **Deliverable:** source code, synthetic sample data, tests and README.

## 3. File Integrity Checker
**Goal:** Calculate file hashes for a test directory and report changes.
- Use a standard cryptographic library.
- Explain that hashes can detect changes but do not identify who made them.
- **Deliverable:** script, sample output, limitations and tests.

## 4. Home Network Diagram
**Goal:** Document a home-lab topology.
- Include device roles, trust boundaries and defensive controls.
- Redact public addresses, SSIDs, serial numbers and personal details.
- **Deliverable:** sanitized diagram and security observations.

## 5. Security Awareness Mini-Guide
**Goal:** Explain phishing indicators and safe reporting.
- Use fictional examples only.
- Do not create credential-harvesting pages or collect credentials.
- **Deliverable:** one-page awareness guide and quiz.
