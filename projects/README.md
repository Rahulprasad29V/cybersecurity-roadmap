# CyberWolf Practical Projects

Projects turn knowledge into demonstrable evidence. Start small, document clearly, and keep all testing inside a local lab or explicitly authorized scope.

## Project workflow
1. Define the problem and intended user.
2. Set scope, assumptions and safety boundaries.
3. Identify data sources and privacy considerations.
4. Build a minimal version.
5. Test normal, edge and failure cases.
6. Document setup, usage, limitations and remediation.
7. Remove secrets and sensitive data before publishing.

## Beginner
- Personal cybersecurity baseline checklist.
- Python parser for synthetic log files.
- File integrity checker using standard hashing libraries.
- Sanitized home-network diagram.
- Security awareness guide using fictional examples.

## Intermediate
- Packet capture investigation using benign traffic.
- Secure web application review of a local intentionally vulnerable app.
- Synthetic authentication-alert triage.
- Vulnerability management tracker with sample data.
- Demo CI pipeline with dependency and secret scanning.

## Advanced
- Detection engineering lab using synthetic or lab telemetry.
- Cloud security posture review in a sandbox or sample architecture.
- Digital forensics case simulation using a training dataset.
- Secure reference architecture for a fictional organization.
- Defensive security automation platform with tests and auditability.

Every project should include a README, scope, methodology, evidence, test results, remediation or defensive lessons, and limitations. Never publish real credentials, private keys, personal data or sensitive target details.
