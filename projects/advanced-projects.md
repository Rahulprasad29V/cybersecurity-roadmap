# Advanced Projects

## 1. Detection Engineering Lab
Build a local telemetry pipeline using synthetic or lab data. Define a threat hypothesis, identify required telemetry, test detection logic, measure false positives and document blind spots.
**Deliverable:** detection specification, test cases and analyst runbook.

## 2. Cloud Security Posture Review
Use a sandbox account or provided architecture dataset. Review IAM, network exposure, logging, storage, encryption and backups. Check cost before creating resources.
**Deliverable:** prioritized findings and remediation plan.

## 3. Digital Forensics Case Simulation
Use a training dataset. Preserve original evidence, record hashes, build an event timeline, and separate facts from hypotheses.
**Deliverable:** case notes, evidence log and final report.

## 4. Secure Reference Architecture
Design a secure architecture for a fictional small organization. Include identity, network segmentation, endpoint management, logging, backup and recovery. Map threats to controls and residual risks.
**Deliverable:** architecture diagram, threat model and control matrix.

## 5. Defensive Security Automation
Build a tool that ingests sample findings and produces a prioritized report. Validate inputs and include tests, access controls and audit logs if a web interface is used.
**Deliverable:** source, architecture, test report and limitations.

Advanced does not mean intrusive. Keep experiments isolated and authorized.
