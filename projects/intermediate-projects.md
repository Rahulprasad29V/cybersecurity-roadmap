# Intermediate Projects

## 1. Packet Capture Investigation
Analyze a benign capture generated by your own device or a training dataset. Identify DNS, TCP and TLS metadata, build a timeline, and explain what cannot be inferred.
**Deliverable:** sanitized packet-analysis report.

## 2. Secure Web Application Review
Review a deliberately vulnerable local application. Map authentication, authorization, input handling and session controls. Fix one issue and add a regression test.
**Deliverable:** threat model, finding, patch and test evidence.

## 3. Synthetic Authentication Alert Triage
Use synthetic login events, define suspicious patterns and likely false positives, and produce an analyst note with confidence and next steps.
**Deliverable:** sample dataset, detection logic in plain English and triage report.

## 4. Vulnerability Management Tracker
Create a small tracker with asset, finding, severity, owner, due date and status. Explain risk-based prioritization.
**Deliverable:** spreadsheet or small app with sample data.

## 5. Secure CI Pipeline
Use a demo repository. Add dependency review, secret scanning and static analysis. Never commit real secrets.
**Deliverable:** workflow, sample findings and remediation notes.
