# Learning Path: SOC Analyst

**Goal:** Develop the ability to monitor security telemetry, triage alerts, investigate suspicious activity and communicate findings.

## Prerequisites
Networking fundamentals, Windows and Linux basics, authentication concepts, and basic scripting.

## Learning sequence
1. Windows Event Logs, Sysmon concepts and Linux authentication logs.
2. DNS, HTTP, network flows and packet metadata.
3. SIEM concepts: collection, parsing, normalization, correlation and dashboards.
4. Alert triage, evidence quality, false positives and escalation.
5. Incident response lifecycle, containment decisions and post-incident learning.
6. Detection engineering fundamentals and threat-intelligence context.

## Practice
- Analyze synthetic login and endpoint event datasets.
- Write an alert triage note that separates observations from hypotheses.
- Create a detection idea and document its data requirements and false-positive risks.
- Complete a blue-team lab from the [lab catalog](../labs/catalog.md).

## Portfolio evidence
A sanitized alert investigation, a detection specification, a small analyst runbook and a tabletop incident report.

## Readiness checkpoint
Explain what the alert proves, what remains unknown, what additional evidence is needed and when to escalate. Never claim attribution from a single indicator.
