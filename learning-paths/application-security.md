# Learning Path: Application Security

**Goal:** Build and assess applications with security integrated into design, development and delivery.

## Prerequisites
Programming fundamentals, HTTP, databases, authentication concepts and Git.

## Learning sequence
1. Secure software development lifecycle and threat modeling.
2. Authentication, authorization, sessions and account recovery.
3. Input handling, output encoding, injection prevention and safe file handling.
4. OWASP Top 10 and Application Security Verification Standard (ASVS).
5. Code review, dependency management, secrets handling, SAST and DAST.
6. Security testing, regression tests and developer-friendly remediation.

## Practice
Review a local intentionally vulnerable application. Fix one issue and write a regression test. Use [PortSwigger Web Security Academy](https://portswigger.net/web-security) or OWASP training projects within their published rules.

## Portfolio evidence
A threat model, secure code change, test evidence and a concise developer-facing security review.

## Readiness checkpoint
Explain root cause and threat model, show the defensive code change and demonstrate that the fix is covered by tests.
