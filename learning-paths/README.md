# CyberWolf Learning Paths

Learning paths combine existing topic guides, labs, quizzes and projects into role-oriented sequences. Complete the common foundations first; specialization paths are guides, not guarantees of job readiness.

## Common foundation
1. Computer and networking fundamentals.
2. Linux and Windows administration.
3. Python or another suitable scripting language.
4. Security principles, identity and cryptography.
5. Logging, risk and ethical practice.
6. Clear technical writing and evidence handling.

## Choose a specialization

| Path | Best starting point | Focus |

| [Application Security](application-security.md) | Programming + web fundamentals | Secure design, code review and testing |

| [GRC Analyst](grc-analyst.md) | Security fundamentals + communication | Risk, policies, controls and assurance |
| [Threat Intelligence Analyst](threat-intelligence.md) | Networking + defensive security | Intelligence lifecycle and analytic writing |

## How to use a path
- Start with the prerequisites listed in the track.
- Select one primary path; add a second only after building practical depth.
- Complete at least one lab and one portfolio project.
- Maintain a learning journal and record the limitations of your work.
- Revisit the path every quarter as tools, standards and role expectations change.

## Career note
A roadmap can organize learning, but cannot promise employment or replace formal experience, mentorship, communication skills or employer-specific requirements.
