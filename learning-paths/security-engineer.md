# Learning Path: Security Engineer

**Goal:** Design, implement and maintain security controls across systems and services.

## Prerequisites
Networking, Linux/Windows, scripting, identity and security fundamentals.

## Learning sequence
1. System hardening and secure configuration baselines.
2. Identity, privileged access and secrets management.
3. Network segmentation, endpoint protection and centralized logging.
4. Vulnerability and patch management.
5. Security automation, infrastructure as code and CI/CD controls.
6. Architecture reviews, threat modeling and incident readiness.

## Practice
Harden a disposable VM, document before-and-after settings, and create a small defensive automation tool that works on sample data.

## Portfolio evidence
Hardening baseline, architecture diagram, automation project and control verification report.

## Readiness checkpoint
Explain control objectives, operational impact, failure modes, monitoring and rollback strategy.
