# Learning Path: Cloud Security

**Goal:** Understand and reduce risks in cloud identities, networks, workloads and data.

## Prerequisites
Networking, IAM basics, Linux, web fundamentals and scripting.

## Learning sequence
1. Shared responsibility and cloud account structure.
2. IAM roles, policies, least privilege and workload identity.
3. Network segmentation, private endpoints and ingress/egress controls.
4. Storage permissions, encryption, key management and audit logs.
5. Containers, infrastructure as code and CI/CD security.
6. Cloud posture review, incident response and cost awareness.

## Practice
Use a sandbox account or sample architecture. Review a sample IAM policy and storage configuration. Never create billable resources without understanding potential costs.

## Portfolio evidence
A cloud threat model, IAM review, network diagram and prioritized posture assessment.

## Readiness checkpoint
Identify the asset, trust boundary, excessive permission or exposure, potential impact and practical least-privilege remediation.
