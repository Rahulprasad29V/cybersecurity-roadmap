# Learning Path: Penetration Tester

**Goal:** Learn to assess systems under explicit authorization, validate findings safely and produce useful reports.

## Prerequisites
TCP/IP, Linux, scripting basics, web fundamentals, security concepts and clear technical writing.

## Learning sequence
1. Authorization, scope, exclusions, rules of engagement and stop conditions.
2. Asset inventory and reconnaissance concepts in controlled labs.
3. Service identification and vulnerability assessment.
4. Web application security and secure validation.
5. Evidence handling, risk reasoning and remediation.
6. Retesting, report writing and responsible disclosure.

## Practice
Use only a local vulnerable VM, training application or target explicitly assigned by a platform. Complete low-impact exercises, then write a finding using the [vulnerability report template](../templates/vulnerability-report.md).

## Portfolio evidence
A scoped assessment plan, a sanitized lab report, a remediation guide and a retest record.

## Readiness checkpoint
Demonstrate that you can stay in scope, stop when uncertain, distinguish scanner output from verified findings and explain realistic impact without exaggeration.
