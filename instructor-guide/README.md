# CyberWolf Instructor and Facilitator Guide

This guide supports instructors, mentors and peer facilitators using the repository in workshops, bootcamps or self-paced cohorts.

## Delivery models
- **Self-paced:** learners select a path, work through content and keep private progress copies.
- **Mentored cohort:** facilitator assigns weekly outcomes, reviews artifacts and leads retrospectives.
- **Workshop:** one module is taught with a short concept briefing, guided activity and reflection.
- **Capstone studio:** teams complete a scoped capstone and present evidence to a review panel.

## Suggested 12-week cohort
| Week | Focus | Learner output |
|---:|---|---|
| 1 | Orientation, safety and systems | Lab plan and learning journal |
| 2 | Networking | Packet review report |
| 3 | Linux, Windows and scripting | Log parser mini-project |
| 4 | Security fundamentals and identity | Threat model |
| 5 | Defensive security | Alert triage note |
| 6 | Authorized assessment methodology | Scoped assessment plan |
| 7 | Web security | Local lab finding and fix |
| 8 | Cloud and containers | Cloud posture review |
| 9 | DFIR and incident response | Timeline and evidence log |
| 10 | Specialization track | Track-specific lab |
| 11 | Capstone build and review | Draft capstone package |
| 12 | Capstone presentation | Final report and retrospective |

## Facilitation checklist
- [ ] Confirm lab environments, authorization and safety boundaries.
- [ ] Explain that self-study quizzes are not formal examinations.
- [ ] Provide accessible copies of datasets and templates.
- [ ] Review evidence for privacy before learners publish it.
- [ ] Use rubrics consistently and provide actionable feedback.
- [ ] Keep learner records private and follow institutional data policies.

## Assessment
Use the [assessment rubrics](../assessments/README.md). A facilitator should assess evidence and reasoning, not tool count or speed.

## Cohort privacy
Do not collect student credentials, private notes or sensitive screenshots in public GitHub issues. Use institution-approved private channels for learner records.


## Advanced curriculum delivery
For advanced cohorts, use the [advanced module catalog](../advanced/README.md), the [30-day engineering challenge](../advanced/30-day-challenge.md) and the [capstone briefs](../capstones/README.md). Learners should work with the synthetic [dataset catalog](../datasets/README.md) unless a separately approved lab environment is provided.

Advanced submissions should be reviewed with the [capstone rubric](../assessments/rubrics/capstone.md), [architecture rubric](../assessments/rubrics/architecture-review.md) and [oral-defense rubric](../assessments/rubrics/oral-defense.md).
